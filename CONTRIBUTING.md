# Contributing to Puldistro

Thanks for helping improve Puldistro.

Puldistro is meant to help people choose Linux with clear, honest, beginner-friendly information. Contributions should make the site easier to understand, more accurate, or more useful for people considering a switch to Linux.

## Good contribution ideas

- Improve unclear wording or simplify explanations
- Add or correct Linux distribution information
- Add useful Windows/macOS app alternatives
- Improve glossary entries
- Improve German or English translations
- Report recommendations that feel misleading
- Report broken links, layout issues, or confusing pages
- Suggest better fallback advice for apps, games, or hardware

## Content style

Please keep contributions:

- **Beginner-friendly** — avoid jargon where possible
- **Honest** — do not promise that Linux will work for every device, app, or game
- **Neutral** — avoid distro wars and fanboy language
- **Practical** — focus on real user decisions and common migration problems
- **Privacy-aware** — do not add tracking, unnecessary data collection, or external dependencies without a strong reason

## Before suggesting a change

For content changes, please check:

- Is the information still current?
- Is it useful for someone new to Linux?
- Does it explain trade-offs clearly?
- Could it create unrealistic expectations?

## Reporting bugs

When reporting a bug, include:

- Which page has the problem
- What you expected to happen
- What actually happened
- Your browser and device, if it is a display or interaction issue
- A screenshot if it helps explain the problem

## Suggesting features

Feature suggestions are welcome, especially if they help users make safer Linux migration decisions.

Good feature requests explain:

- Who the feature helps
- What problem it solves
- Why it fits Puldistro
- Any risks, such as making the quiz too complicated

## Pull requests

Before opening a pull request:

- Keep the change focused and easy to review
- Match the existing tone and visual style
- Update both English and German text when changing visible content, if possible
- Test the changed page in a browser
- Avoid adding unnecessary complexity

## Code of conduct

Please be respectful and constructive. This project follows the rules in `CODE_OF_CONDUCT.md`.
